# Announcement Images & Event Flyers

This folder hosts single-use images, event flyers, campus announcements, and one-off graphics used in Canvas LMS course announcements.

## Usage in Canvas

Images uploaded to this folder can be embedded directly into Canvas announcements using either of the following URLs:

- **GitHub Raw URL:**  
  `https://raw.githubusercontent.com/OpenAudioOER/canvas-announcements/main/images/<filename>`

- **GitHub Pages URL:**  
  `https://openaudiooer.github.io/canvas-announcements/images/<filename>`

## Adding New Images via GitHub Web UI

1. Open the [OpenAudioOER/canvas-announcements images folder](https://github.com/OpenAudioOER/canvas-announcements/tree/main/images) in your browser.
2. Click **Add file** > **Upload files**.
3. Drag and drop your image file and commit changes.
